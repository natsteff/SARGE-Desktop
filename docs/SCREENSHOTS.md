# Windows screenshot checklist

Capture the installed SARGE Desktop beta on the Windows PC with the current catalog. Screenshots from the old localhost Docker app do not represent this application. Do not substitute generated screens or fabricated inventory.

1. Install the current beta, open SARGE Desktop, and confirm its version in the sidebar.
2. Use the default theme for all standard screenshots. Set a consistent window size, around 1380 × 900, and close tooltips, dialogs and transient notices unless demonstrating them.
3. Capture Photo inventory with previews and representative saved EXIF columns, Drives & locations with online/offline counts, and Scan activity. Show real registered names only after checking that they are suitable for a public README.
4. Capture one Photo inventory example with Solly’s Soldiers · Dark selected, including the Appearance switcher and alternate logo. Restore the default theme afterward.
5. Use Windows Snipping Tool to capture the app window. Save PNGs under docs/images as inventory-default.png, drives-default.png, activity-default.png and theme-soldiers.png.
6. Add these actual captures to README.md, with descriptive alt text. Default-theme screenshots should be the primary examples; use only the single dark-theme example.

A Codex chat running on the Windows PC can update the README from those saved files and publish them to this repository. Desktop automation capabilities and permission availability on that PC determine whether it can capture the window directly; manual Snipping Tool captures also work.
