## Capture and handoff

1. Use the real installed Windows app, confirm its actual version, and use an authorized sample catalog. Never fabricate records or relabel old screenshots.
2. Prefer one consistent window size around 1380–1600 pixels wide and enough height for the relevant controls. Avoid maximizing on an ultrawide display: unused space makes README text tiny. Check a test capture before collecting the batch.
3. Use the default theme except for the one dark example; restore the default afterward. Keep relevant controls visible and move the pointer away from the subject when practical.
4. Review paths, names, volume identifiers and photo previews for public suitability. Store review candidates privately in sarge-testing with the actual version/date, checksums and a completed manifest. A ZIP is optional if individual files are already committed.
5. Report missing views or limitations once. Stop when the agreed list is captured; request clarification rather than expanding the assignment. Public use requires Nate’s authorization.
6. Update only selected README images and truthful captions/alt text. Preserve original unedited captures and their version provenance. Screenshot review is separate from functional acceptance or a passed retest.
