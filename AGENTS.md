# SARGE Desktop project instructions

## Release documentation and screenshots

- For every published release, update the root README latest-release version label and download link, plus the version heading and release link in desktop/README.md. Do this even when other README content or screenshots are on hold. Verify the linked release exists.
- Screenshot updates are a separate decision. Before publishing, ask the user yes/no whether to refresh README screenshots, recommending an answer based on the most recent captures and UI changes since then. Honor an explicit decision already given for that release, including testing first and providing captures later.
- Keep existing screenshots accurately labeled with the version they actually show; never relabel old captures as a newer release.
- Update broader README content and screenshots only within the user's authorized scope.
